# Make this desk yours

Read CLAUDE.md and the operator's brief. Inspect the schema and the current records. Explain the proposed field, terminology or review-policy change. Write a new numbered migration in supabase/migrations and update the CLI, tests, documentation and affected views. Never edit an applied migration. Check whether previous reviews need invalidating. Apply with npm run migrate to the agreed database, then npm test in its temporary database. Report the change and evidence. Do not delete records or modify a source system. Keep CLAUDE.md and AGENTS.md usable by every coding agent.
