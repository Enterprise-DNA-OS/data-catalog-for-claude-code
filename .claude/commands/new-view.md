# Add a read-only report

Read views.json and the existing database views. Ask what decision the report supports if the brief does not say. Add a named report using SELECT queries only, with clear labels, owners and dates. Use the shared renderer and brand.json. Run npm run view and inspect the HTML. No buttons that mutate, no web server and no public sharing. Never claim source coverage beyond recorded metadata.
