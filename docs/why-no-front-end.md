# Why this desk has no front end

The weekly work is to agree definitions, assign owners, review changes, record evidence and ask what a change affects. Those are records and repeatable questions. Claude Code, Codex, OpenCode or Cursor reads the same instructions and calls the same CLI.

A screen is useful for graphical lineage exploration, browsing a large catalogue, collaborative editing and mobile access. This base has no interactive diagram, offline mobile workflow, automatic source scanner or portal. Its HTML views and documents are read-only snapshots. Regenerate them after records change. They do not have access control of their own.

Enterprise DNA scopes a web front end, connectors and a different stack when those are needed in the customer's version. Omni by Enterprise DNA installs and runs it for one setup fee, then a retainer. The database and its definitions remain the business's own.
